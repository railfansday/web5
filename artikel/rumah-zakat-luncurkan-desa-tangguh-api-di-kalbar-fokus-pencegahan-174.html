Rumah Zakat Luncurkan Desa Tangguh Api di Kalbar, Fokus Pencegahan dan Pemulihan Karhutla

It has been revealed that KUBU RAYA -- Rumah Zakat meluncurkan program Desa Tangguh Api di Kalimantan Barat untuk meningkatkan kesiapsiagaan masyarakat menghadapi kebakaran hutan dan lahan (Karhutla) sekaligus mendorong pemulihan lingkungan. Program ini mengandalkan keterlibatan masyarakat melalui Rumah-Rumah Siaga Jaga Api sebagai pusat pemantauan lingkungan, pencegahan kebakaran, dan kegiatan penghijauan. Program Desa Tangguh Api mengusung pendekatan penanggulangan Karhutla yang tidak hanya berfokus pada pemadaman, tetapi juga pencegahan dan pemulihan lahan terdampak. Melalui Rumah-Rumah Siaga Jaga Api, masyarakat diharapkan dapat berkoordinasi, meningkatkan kesiapsiagaan, serta menggerakkan upaya menjaga lingkungan. Baca Juga Pulihkan Wilayah Terdampak Karhutla, Baznas Tanam 10.500 Pohon di 56 Kabupaten/Kota Indahkus dan Rumah Zakat Tanam Pohon di Lahan Bekas Karhutla Kalimantan Pos Medis Dompet Dhuafa Layani Warga Terdampak Karhutla Papua Disaster Management Dept. Head Rumah Zakat, Bagas Dwi Satriyo, mengatakan penanggulangan Karhutla perlu dilakukan secara menyeluruh, mulai dari pencegahan hingga pemulihan lingkungan. “Rumah Zakat memandang bahwa penanggulangan Karhutla tidak cukup hanya dengan memadamkan api ketika kebakaran terjadi. Kita harus membangun sistem pencegahan dan kesiapsiagaan yang kuat dengan menempatkan masyarakat sebagai aktor utama. “Melalui Desa Tangguh Api, kami ingin mendorong masyarakat agar memiliki kapasitas untuk mengenali risiko, melakukan pemantauan lingkungan, mencegah kebakaran, serta terlibat aktif dalam pemulihan lahan pasca-Karhutla,” ujar Bagas, Rabu (25/11). Bagas mengatakan, keterlibatan masyarakat diperlukan karena warga memiliki kedekatan dengan wilayah tempat tinggalnya sehingga dapat mengenali potensi ancaman dan ikut menjaga keberlanjutan upaya pemulihan. “Bagi kami, menjaga lingkungan juga berarti menjaga kehidupan masyarakat hari ini dan masa depan generasi mendatang. Karena itu, upaya pemulihan tidak boleh berhenti pada penanganan darurat. Harus ada langkah berkelanjutan agar masyarakat dapat hidup berdampingan dengan lingkungan yang lebih terjaga,” tambahnya. Melalui program Desa Tangguh Api, Rumah Zakat juga mendorong pemulihan lahan pasca-Karhutla melalui penanaman kembali pepohonan dan perawatan ekosistem. Program ini diharapkan dapat menjadi inisiatif perintis di Kalimantan Barat yang mendorong desa lain membangun kesiapsiagaan dan pemulihan lingkungan berbasis masyarakat. Rumah Zakat berharap keterlibatan masyarakat dan kolaborasi dalam program tersebut dapat menjadi gerakan berkelanjutan untuk mencegah kebakaran, memulihkan lahan, serta menjaga lingkungan di wilayah yang pernah terdampak Karhutla.
